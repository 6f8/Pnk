# كاشف — تحليل بانك الآيفون

برنامج ويندوز (C# / WinForms) يقرأ ملفات **panic-full** من الآيفون أو نصها الملصوق، ويعطي التشخيص والأسباب مرتبة وخطوات الفحص والأدلة من السجل.

- البرنامج: [`Kashif/`](Kashif/) — راجع [`Kashif/README.md`](Kashif/README.md) لطريقة التشغيل ودليل الشاشات.
- اختبارات محرك التحليل: [`Kashif.Tests/`](Kashif.Tests/) — `dotnet run --project Kashif.Tests`
